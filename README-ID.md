## 🚀 Mulai Cepat (5 Menit)

### Opsi 1: Setup Otomatis (Direkomendasikan) ⭐

Cara tercepat untuk memulai! Script akan mengurus semuanya untuk Anda.

#### Untuk macOS/Linux:

```bash
# 1. Clone repository
git clone https://github.com/yourusername/portfolio.git
cd portfolio

# 2. Jalankan setup otomatis
npm run setup

# 3. Edit informasi Anda
nano lib/data.ts

# 4. Jalankan development server
npm run dev
```

#### Untuk Windows:

```powershell
# 1. Clone repository
git clone https://github.com/yourusername/portfolio.git
cd portfolio

# 2. Jalankan setup otomatis
npm run setup:windows

# 3. Edit informasi Anda (gunakan editor favorit Anda)
# Buka lib/data.ts

# 4. Jalankan development server
npm run dev
```

**Script otomatis akan:**
- ✅ Cek versi Node.js (minimal 18.x)
- ✅ Install semua dependencies
- ✅ Buat file `.env.local` dari template
- ✅ Jalankan verifikasi setup
- ✅ Memberitahu jika ada yang perlu diperbaiki

### Opsi 2: Setup Manual

Jika Anda lebih suka kontrol penuh:

```bash
# 1. Clone repository
git clone https://github.com/yourusername/portfolio.git
cd portfolio

# 2. Install dependencies
npm install

# 3. Copy environment file
cp .env.example .env.local

# 4. Edit .env.local dengan editor favorit Anda
nano .env.local

# 5. Jalankan development server
npm run dev
```

### 🎉 Selesai!

Buka browser dan kunjungi: **http://localhost:3000**

Anda akan melihat portfolio Anda berjalan! 🎊

### Langkah 4: Setup GitHub Integration

Edit bagian GitHub config:

```typescript
export const githubConfig = {
  username: 'github-username-anda',  // ⬅️ GANTI dengan username GitHub Anda
  maxRepos: 6,  // Jumlah project yang ditampilkan
  excludeRepos: [],  // Repo yang tidak ingin ditampilkan
};
```

Lalu tambahkan GitHub token ke `.env.local`:

```env
GITHUB_TOKEN=your_github_token_here
GITHUB_USERNAME=your_github_username
```

**Cara mendapatkan GitHub token:**

1. Buka [GitHub Settings > Developer Settings > Personal Access Tokens](https://github.com/settings/tokens)
2. Klik "Generate new token (classic)"
3. Beri nama "Portfolio Website"
4. Pilih scope: `public_repo` saja
5. Generate dan copy token
6. Paste ke `.env.local`

## 🚀 Deployment

### Deploy ke Vercel (Paling Mudah) ⭐

Vercel adalah platform dari pembuat Next.js. **Gratis untuk personal projects!**

#### Cara 1: Deploy via Website (Termudah)

1. Push kode Anda ke GitHub
2. Kunjungi [vercel.com](https://vercel.com/)
3. Sign up dengan akun GitHub
4. Klik "New Project"
5. Import repository Anda
6. Vercel akan auto-detect Next.js
7. Tambahkan environment variables:
   - `GITHUB_TOKEN`
   - `GITHUB_USERNAME`
   - `NEXT_PUBLIC_SITE_URL`
8. Klik "Deploy"

**Selesai!** Website Anda live dalam 2 menit! 🎉

#### Cara 2: Deploy via CLI

```bash
# Install Vercel CLI
npm i -g vercel

# Login
vercel login

# Deploy
vercel --prod
```

### Deploy ke Netlify

Netlify juga gratis dan mudah!

```bash
# Install Netlify CLI
npm i -g netlify-cli

# Login
netlify login

# Deploy
netlify deploy --prod
```

Config sudah ada di `netlify.toml`.

### Deploy dengan Docker

```bash
# Build image
npm run docker:build

# Run production
npm run docker:prod
```

Atau manual:

```bash
docker build -t portfolio:latest .
docker run -p 3000:3000 portfolio:latest
```

### Deploy ke VPS (DigitalOcean, AWS, dll)

```bash
# Di server Anda
git clone https://github.com/yourusername/portfolio.git
cd portfolio
npm install
npm run build

# Jalankan dengan PM2
npm i -g pm2
pm2 start npm --name "portfolio" -- start
pm2 save
pm2 startup
```

## 🐛 Troubleshooting

### Problem: Port 3000 sudah digunakan

```bash
# Gunakan port lain
PORT=3001 npm run dev
```

### Problem: Node.js versi terlalu lama

```bash
# Cek versi
node -v

# Update Node.js ke versi 18+ dari nodejs.org
```

### Problem: Dependencies tidak terinstall

```bash
# Hapus node_modules dan install ulang
rm -rf node_modules package-lock.json
npm install
```

### Problem: Build gagal

```bash
# Clean install
rm -rf node_modules .next
npm install
npm run build
```

### Problem: GitHub API tidak menampilkan repositories

**Cek 1:** Pastikan GITHUB_TOKEN ada di `.env.local`

```env
GITHUB_TOKEN=your_token_here
GITHUB_USERNAME=your_username
```

**Cek 2:** Pastikan token memiliki scope `public_repo`

**Cek 3:** Cek di browser console apakah ada error

### Problem: Gambar tidak muncul

- Pastikan file gambar ada di folder `public/`
- Cek path gambar di `lib/data.ts`
- Contoh: `/profile.jpg` untuk file di `public/profile.jpg`

### Problem: Setup script gagal di Windows

```powershell
# Jalankan PowerShell sebagai Administrator
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# Coba lagi
npm run setup:windows
```

### Problem: Styling tidak muncul

```bash
# Restart dev server
# Tekan Ctrl+C untuk stop
npm run dev
```

### Problem: TypeScript errors

```bash
# Run type check untuk melihat semua error
npm run type-check

# Perbaiki satu per satu
```

## ❓ FAQ

### Q: Apakah gratis?

**A:** Ya! 100% gratis. Codenya open source (MIT License) dan hosting di Vercel/Netlify juga gratis untuk personal projects.

### Q: Apakah saya harus paham coding?

**A:** Tidak perlu expert! Jika Anda bisa copy-paste dan edit text, Anda sudah bisa. Yang perlu Anda edit hanya file `lib/data.ts` dan `.env.local`.

### Q: Berapa lama setup?

**A:** Dengan script otomatis: **5-10 menit**. Manual: **15-20 menit**.

### Q: Apakah bisa untuk fresh graduate?

**A:** Sangat cocok! Template ini dirancang khusus untuk fresh graduate yang belum punya banyak project. GitHub integration akan menampilkan repository Anda secara otomatis.

### Q: Bagaimana cara update konten?

**A:** Edit file `lib/data.ts`, save, dan website otomatis update (di dev mode). Untuk production, push ke GitHub dan Vercel akan auto-deploy.

### Q: Apakah responsive di mobile?

**A:** Ya! Design mobile-first, sudah dioptimalkan untuk semua ukuran layar.

### Q: Bagaimana cara menambah halaman baru?

**A:** Buat file baru di folder `app/`. Contoh: `app/blog/page.tsx` akan membuat halaman `/blog`.

### Q: Apakah bisa pakai domain sendiri?

**A:** Ya! Di Vercel/Netlify bisa connect domain custom. Mereka punya tutorial lengkap.

### Q: Bagaimana cara update dependencies?

```bash
npm update
# Atau untuk major updates
npx npm-check-updates -u
npm install
```

### Q: Apakah SEO friendly?

**A:** Ya! Sudah ada meta tags, Open Graph, sitemap otomatis, dan optimasi SEO lainnya.

### Q: Bisa tambah blog?

**A:** Ya! Template ini siap untuk MDX blog. Cek dokumentasi Next.js tentang MDX.

### Q: Support TypeScript saja atau JavaScript juga?

**A:** Template ini pakai TypeScript, tapi Anda bisa rename file `.ts` ke `.js` dan hapus type annotations jika mau pakai plain JavaScript.
