🚀 QUICK START (5 MINUTES)
═══════════════════════════════════════════════════════════════════════════

1. Setup Environment
   npm install (if needed)

2. Configure .env.local
   ADMIN_PASSWORD=your-strong-password
   MASTER_KEY=your-random-32-char-key
   MONGODB_URI=your-mongodb-connection
   NEXT_PUBLIC_SITE_URL=http://localhost:3000

3. Run Locally
   npm run dev
   Homepage: http://localhost:3000
   Admin:    http://localhost:3000/admin

4. Test Admin Panel
   Login with ADMIN_PASSWORD
   Upload test certificate
   View certificate in gallery

🎯 COMMON TASKS
═══════════════════════════════════════════════════════════════════════════

UPLOAD CERTIFICATE
  1. Go to /admin
  2. Login with password
  3. Click "Certificates" tab
  4. Click "Upload Sertifikat Baru"
  5. Fill form (Image, Title, Issuer, Date, optional Expiry)
  6. Click "Upload"

VIEW CERTIFICATE (User)
  1. Go to home page
  2. Scroll to "Certificates" section
  3. Click "View Certificate"
  4. Modal opens with protected image
  5. View valid for 1 hour

DELETE CERTIFICATE
  1. Login to /admin
  2. Click "Certificates" tab
  3. Find certificate to delete
  4. Click "Hapus" button
  5. Confirm

DEPLOY TO PRODUCTION
  Vercel: vercel deploy --prod
  Custom: npm run build && npm start

🔐 SECURITY FEATURES
═══════════════════════════════════════════════════════════════════════════

LOGIN PROTECTION
  • Rate limit: 5 attempts per 15 minutes
  • Password hashing: SHA-256
  • Session: 24-hour expiry

UPLOAD PROTECTION
  • File validation: MIME type, size, extension
  • Rate limit: 10 uploads per 5 minutes
  • Max size: 5 MB

CERTIFICATE PROTECTION
  • View tokens: 1-hour validity
  • Download prevention: Headers protect images
  • View logging: All views tracked

API SECURITY
  • XSS prevention: Input sanitization
  • CSRF protection: Token-based
  • Security headers: CSP, X-Frame-Options, etc

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

ADMIN LOGIN NOT WORKING?
  ✓ Check ADMIN_PASSWORD in .env.local
  ✓ Wait 15 min if rate limited (5 attempts/15 min)
  ✓ Clear browser cookies and retry

CERTIFICATE UPLOAD FAILS?
  ✓ File format: JPG, PNG, or WEBP only
  ✓ File size: Max 5 MB
  ✓ /public/certificates/ must be writable

CERTIFICATE VIEW BLANK?
  ✓ Token expires after 1 hour
  ✓ Check file exists on server
  ✓ Check browser console for errors

SECURITY HEADERS MISSING?
  ✓ Middleware.ts must be running
  ✓ Restart development server
  ✓ Check DevTools > Network > Response Headers
