## 🐛 Troubleshooting

**Animations not working?**
→ Run `npm install` and restart dev server

**GitHub repos not loading?**
→ Check `.env` file has GITHUB_TOKEN and GITHUB_USERNAME

**Profile image not showing?**
→ Replace placeholder at `/public/profile.jpg` with real image

**Navigation not scrolling?**
→ Section IDs must match: hero, about, skills, projects, contact
