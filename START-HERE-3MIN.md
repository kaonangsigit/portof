## 🆘 Common Issues

**Port already in use?**
```bash
lsof -ti:3000 | xargs kill -9
lsof -ti:5000 | xargs kill -9
npm run dev
```

**Database connection failed?**
```bash
brew services restart postgresql
npm run db:setup
```

**Module not found?**
```bash
rm -rf node_modules package-lock.json
npm install
```
